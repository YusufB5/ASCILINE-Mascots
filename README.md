# 🐱 ASCILINE Mascots & GIF Studio

An interactive, lightweight ASCII Mascot Engine for the web, featuring custom point hitboxes, color animations, interactive physics (drag & throw, platform landing), and a built-in GIF Studio editor.

## ✨ Features

- **Interactive Mascot Physics**: Walking, gravity, bouncing, platform collisions, and drag & throw dynamics.
- **GIF Studio Editor** (`tools/gif_studio.html`): Load GIFs or image sequences, adjust color palettes, crop frames, and configure custom hitboxes (points, rects, circles).
- **Custom Hitbox System**: Precise polygon/point/rect/circle hitboxes visualized directly on mascots.
- **Color & Text Animation Modes**: Full support for colored HTML spans and classic plain ASCII text animations.

## 🚀 Quick Start

1. Open `example/index.html` in your web browser to test the live mascot engine.
2. Open `tools/gif_studio.html` to create and export your own ASCII mascot animations (`.json`).
